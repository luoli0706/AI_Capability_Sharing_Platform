当前大模型与 AI Agent 技术快速演进，在项目化的智能化团队协同开发场景中，团队内多个 Agent、自动化工作流、AI 应用往往会复用同一批基础设施：包括 MCP 服务、私有知识库、技能集（Skills）、自定义 Agent 实例、提示词模板等资源。如果各个业务项目独立维护一套 AI 能力组件，会出现资源重复搭建、版本不一致、权限管控混乱、能力难以复用、资产沉淀困难等问题，同时新增 AI 能力的发布、权限申请、使用统计缺少统一流程，大幅提升团队开发与运维成本。
针对上述痛点，本课题基于前后端分离架构，选用 Go Echo 作为后端 Web 开发框架、Vue3作为前端交互技术栈，利用nginx完成反向代理和负载均衡，设计并实现一套面向研发团队的 AI 能力共享平台。平台对 MCP 服务、Skills 技能、Agent 实例、私有知识库四类核心 AI 资产进行统一托管、版本管理与权限治理，配套实现团队用户注册登录、组织域管理与审批流、资产权限鉴权、能力发布订阅调用、使用数据统计、个人中心等核心业务模块。
平台采用分层的数据模型完成实体、权限、版本、审批记录结构化建模，设计标准化的能力发布、权限申请、审批、调用、回收全流程，将 AI 能力资产的创建、上线、申请使用、调用审计、用量统计实现全链路数字化闭环。平台一方面沉淀团队内部可复用的 AI 能力资产，避免重复开发；另一方面通过域隔离、审批机制、调用日志实现安全管控，兼顾共享便利性与数据安全性，降低团队搭建和接入 AI 能力的成本，为研发人员提供稳定、易用、可审计的 AI 能力共享底座，支撑团队内多 Agent 项目协同开发。
二、技术要求
1.熟悉 Golang  Echo 框架，Vue3框架和前后端分离开发模式，能够独立完成毕业设计开题报告撰写，明确研究背景、目标、总体方案、重难点与实施计划。
2.掌握关系型数据库设计规范，能够基于 MySQL 完成业务实体表、权限表、审批流表、版本记录表、调用日志表的结构设计。
3.完成 AI 能力共享平台完整业务系统设计与工程实现。核心业务模块包含：账号体系（用户注册、登录、密码管理、角色分配、JWT 鉴权）、知识库模块（文档上传、切片入库、元信息编辑、可见范围配置）、AI 资产管理（MCP 服务注册配置、Skills 技能录入、Agent 编排定义、版本管理、上下线发布）、域管理与审批模块（业务域划分、域内资源隔离、权限申请流程、多级审批、调用鉴权拦截）、个人中心（我的资产、我的申请、调用记录、个人信息）；同时提供能力检索、订阅、调用入口与调用指标统计功能。
4.掌握容器化与持续集成部署技术，使用 Docker 对前端、后端、数据库、依赖中间件进行镜像打包，基于 Docker Compose 实现本地开发环境一键拉起；能够设计 CI/CD 流水线，完成代码提交后的自动化构建、单元测试、镜像推送、服务器自动部署，分别验证本地开发环境与云服务器生产环境的部署效果，保障平台服务持续稳定、可访问、可回滚。
